# 使用说明

## 运行

本地可执行预览位于 `artifacts/右键管理-0.1.0.exe`。双击运行即可，不需要在运行时启动 Node.js 服务。需要 Windows 上的 WebView2 Runtime。

当前文件是开发预览构建。源码中保留了独立界面原型，但桌面应用读取真实注册表，不使用原型示例数据。

## 菜单管理

左侧选择文件、文件夹、文件夹空白处、磁盘或文件与文件夹。支持名称、来源、命令搜索，以及已启用、已停用、仅查看筛选。

点击菜单或行末箭头查看详情。普通命令使用开关或详情按钮停用、启用；操作前会显示确认窗口。所有用户的菜单需要 Windows 管理员授权，主界面保持普通权限。

停用只修改目标菜单的 `LegacyDisable` 值，不删除软件的菜单注册键，不加载第三方 Shell 扩展代码。

列表显示注册状态，不等同于当前资源管理器中实际可见的项目。显示还取决于所选对象、Shift 键、应用规则及资源管理器缓存。

## 恢复

操作历史保存修改前后完整菜单结构和原始值类型。恢复时先检查后续操作及当前状态；发生冲突时拒绝覆盖。

如果同一个菜单操作过多次，请从最新的一次开始恢复。中断或失败的操作也会保留记录，可点击恢复重新检查。数据目录显示在操作历史底部，通常位于 `%LOCALAPPDATA%\local.rightclick.manager\history`。

恢复记录不随可执行文件移动或删除。清理数据目录会失去对应的恢复信息。

## 自定义菜单

支持当前用户的 `.exe` 程序和 `.ps1` PowerShell 脚本。选择真实文件、填写菜单名称和显示位置，参数中的 `{path}` 会替换为对应菜单位置的路径占位符。

推荐保留 `"{path}"` 两侧引号，确保含空格的路径作为一个参数传递。PowerShell 脚本遵循系统现有的执行策略。

添加时只写入菜单，不执行程序或脚本。在操作历史中使用“撤销添加”删除本应用创建且未被外部修改的项目。

## 第一版支持范围

- 扫描 HKCU/HKLM 的 64 位 `Software\Classes` 注册表视图。
- 覆盖 `*`、`Directory`、`Directory\Background`、`Drive` 和 `AllFilesystemObjects`。
- 读取普通 `shell` 命令及 `shellex\ContextMenuHandlers` 注册项。
- 可修改已识别的普通静态命令。
- 动态扩展、子菜单、受条件控制的命令、已知系统基础菜单及被用户级记录覆盖的系统级菜单仅查看。
- 尚未扫描特定扩展名、ProgID、32 位注册视图、发送到和 Windows 11 新版菜单。
- 来源按执行命令或组件 DLL 推断，并非软件厂商的权威标识。
