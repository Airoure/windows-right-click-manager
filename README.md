# Windows 右键菜单管理工具

一个本地桌面工具，用于查看、禁用、恢复 Windows 右键菜单项，并添加自定义程序和脚本命令。

## 项目状态

已确定初步技术方案并初始化 Git。当前完成独立的交互原型，等待界面确认后再创建应用脚手架和实现系统功能。

## 查看界面原型

在仓库根目录运行 `node prototype/serve.mjs`，然后访问 http://127.0.0.1:4173 。也可以直接打开 [原型页面](prototype/index.html)。

原型支持分类、搜索、状态筛选、详情、模拟停用与恢复，以及添加自定义菜单。所有数据都是示例，操作不会读取或修改系统注册表，刷新页面会重置。

布局与交互说明见 [原型说明](prototype/README.md)，桌面截图见 [预览图](prototype/preview-desktop.jpg)。

## 技术选型

| 部分 | 技术 | 职责 |
| --- | --- | --- |
| 界面 | React + TypeScript | 分类、搜索、详情、开关和自定义命令编辑 |
| 桌面容器 | Tauri 2 | 窗口、前后端通信和打包 |
| 系统核心 | Rust | 注册表扫描、菜单识别、变更和恢复 |
| 本地存储 | JSON | 设置、操作日志和恢复记录 |

第一版以 Windows 10 的传统右键菜单为验收目标，先完成清理与恢复，再添加自定义菜单。

## 计划能力

- 按文件、文件夹、文件夹空白处和磁盘分类查看菜单注册项。
- 显示菜单名称、来源、作用位置、状态及支持的操作。
- 为已适配的菜单类型提供禁用、恢复和操作历史。
- 添加自定义程序及脚本命令。
- 对未知类型或暂不支持的操作明确标记支持范围。

实现边界和验证方式见 [架构方案](docs/architecture.md)。
