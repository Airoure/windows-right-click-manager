# 界面原型

用于在正式功能开发前确认桌面布局和交互。独立 HTML、CSS 和 JavaScript，无需安装依赖；不包含 Tauri 系统调用。

在仓库根目录运行 `node prototype/serve.mjs`，然后访问 http://127.0.0.1:4173 。也可直接打开 `prototype/index.html`。

## 设计方向

- 以清楚、耐读为主的浅色桌面工具，默认两栏：左侧菜单位置、右侧菜单列表。点击菜单或行末箭头后展开详情侧栏。
- 石板色文字、冷灰底色、蓝色操作强调。主体使用 Segoe UI / Microsoft YaHei UI，命令使用 Consolas。
- 菜单名称与导航采用 15px、600 字重；说明和详情采用 13–14px，并加深颜色。窄窗口保持相同字号，通过改变布局适配空间。
- 详情侧栏中的菜单示意关联当前选中项目，让用户看清启用与停用的影响。
- 默认展示用户截图中的文件夹空白处菜单，所有数据均为手工示例。

## 可体验的流程

- 分类切换、关键词搜索和状态筛选。
- 菜单选择、详情和示意预览。
- 停用确认、恢复、操作历史和恢复冲突提示。
- 添加自定义菜单，撤销添加。
- 重新扫描的加载状态，以及空列表状态。

## 边界

操作仅修改页面内存，刷新页面会重置。程序路径和注册位置为示例，未读取或修改真实注册表。窄窗口使用下拉选择菜单位置，桌面与窄窗口都按需展开详情侧栏。
